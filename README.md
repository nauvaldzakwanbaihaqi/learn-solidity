# Learn Solidity

Project ini adalah repositori sederhana untuk belajar dasar-dasar Solidity menggunakan Remix IDE. Tujuannya bukan untuk aplikasi produksi, melainkan sebagai contoh pembelajaran supaya lebih mudah memahami konsep-konsep dasar smart contract.

## Apa isi project ini?

Project ini berisi beberapa contoh kontrak Solidity yang sederhana dan mudah dipahami:

- Helloworld: contoh kontrak paling dasar dengan variabel pesan yang bisa dilihat publik.
- Counter: contoh kontrak yang memiliki state variable count, lalu bisa ditambah, direset, dan dilihat nilainya.
- EvenOddChecker: contoh kontrak untuk memeriksa apakah suatu angka genap atau ganjil, serta menghitung jumlah dari 1 sampai n.

## Yang dipelajari dari project ini

- Menulis contract di Solidity
- Menggunakan pragma Solidity dan SPDX license
- Membuat state variable dan fungsi
- Memahami fungsi publik, view, dan pure
- Belajar logika sederhana serta loop

## Cara menggunakan

1. Buka project ini di Remix IDE.
2. Pilih file Solidity yang ingin dipelajari, misalnya intro.sol atau counter.sol.
3. Klik Compile untuk mengkompilasi contract.
4. Lalu pilih Deploy untuk mencoba menjalankan kontrak.

## Struktur folder

- intro.sol: contoh kontrak Hello World
- counter.sol: contoh kontrak counter
- EvenOddChecker.sol: contoh kontrak pengecekan bilangan ganjil/genap
- artifacts/: hasil compile dari Remix
- remix.config.json: konfigurasi workspace Remix

## Catatan

Project ini dibuat untuk pembelajaran dan latihan. Tidak ditujukan untuk production atau penggunaan nyata tanpa pengujian lebih lanjut.
